## Features

- **Dark / light theme** with `localStorage` persistence and a no-flash init script
- **Sticky header** with backdrop blur, scroll state and active section highlighting
- **Full-screen mobile menu** with smooth animation
- **Custom cursor** (desktop) with hover states
- **Scroll progress indicator** and **back-to-top** button
- **Scroll reveal animations** via `IntersectionObserver`
- **Animated counters** for the stats section
- **Hero particles** (lightweight canvas, disabled for reduced motion)
- **Magnetic buttons** and subtle parallax
- **Project filtering** by category
- **Case study pages** (`project-details.html?id=...`) rendered from JSON
- **Certificate gallery** with modal viewer
- **Contact form** with validation + Formspree / `mailto:` fallback
- **Copy-email** button with toast notifications
- **Custom 404 page**
- **Accessibility**: semantic HTML, ARIA labels, keyboard nav, skip link, focus states
- **Reduced motion support** throughout
- **SEO**: meta tags, Open Graph, Twitter card, JSON-LD `Person` schema

## Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 (semantic) |
| Styling | CSS3 — custom properties, Grid, Flexbox, fluid `clamp()` typography |
| Behaviour | Vanilla JavaScript (ES2015+) — no frameworks |
| Icons | Inline SVG (no external icon library) |
| Fonts | Inter + Space Grotesk via Google Fonts |
| Data | JSON (`data/*.json`) loaded with `fetch` |
